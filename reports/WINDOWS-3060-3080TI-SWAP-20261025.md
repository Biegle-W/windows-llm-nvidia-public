## Switching back to the original RTX 3060

Return the card to the same slot and boot Windows. Double-click
**Restore RTX3060 Unlock.cmd**, accept UAC, then restart when ready. The helper
refuses a3080Ti, a different3060 board, multiple GPUs, changed BDF/VBIOS/VRAM,
Secure Boot, or an altered dedicated EFI. It verifies the exact saved internal
partition GUID/hash, then makes the existing3060 entry first and Windows second.
It does not reinstall firmware, resize/format partitions or reboot automatically.
The next boot should still be checked; F8 -> Windows Boot Manager bypasses it.

`scripts/Set-GpuBootMode.ps1 -Mode Stock -Elevate` returns to Windows-first order
before another swap. `-Mode Status -Elevate` inspects it. The3060 payload retains
its two complete initial-selector pairs and all other guards; the new card
does not inherit those assumptions.
